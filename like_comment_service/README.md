При получение от клиента id записи и какое-то измени в нем: лайк или же написание комментария, 
сервис `LikesComments` публикует в Kafka события:
- `like.added` — когда пользователь лайкнул статью
- `like.removed` — когда пользователь убрал лайк
- `comment.added` — когда добавлен комментарий
- `comment.removed` — когда удалён комментарий
